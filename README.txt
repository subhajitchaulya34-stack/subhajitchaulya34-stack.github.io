SC Wallpapers - starter website + installable PWA

Files:
- index.html: main wallpaper website
- manifest.json: app install metadata
- sw.js: basic offline caching for core files
- icon.svg: app icon

Publish:
1. Upload all four files (index.html, manifest.json, sw.js, icon.svg) to the ROOT of your GitHub Pages repository.
2. Keep the existing repository's Pages setting enabled for the main branch / root.
3. Open your GitHub Pages website in Chrome on Android.
4. Use Chrome menu > Install app or Add to Home screen when available.

Notes:
- Wallpaper preview links open the original image. Image hosting is remote and needs internet.
- Replace demo photo entries with images you own or have permission to use before public launch.
- This PWA starter is not yet a Play Store APK. An Android package can be made after the website is published and tested.
